# ItsGonzax — sitio personal

HTML + CSS + JS puro, sin build. Listo para GitHub Pages.

## Publicar en GitHub Pages
1. Creá un repositorio (por ejemplo `itsgonzax.github.io` para usar `https://itsgonzax.github.io`, o cualquier nombre).
2. Subí **el contenido** de esta carpeta a la raíz del repo (`index.html`, `css/`, `js/`, `assets/`, `.nojekyll`).
3. En el repo: **Settings → Pages → Build and deployment → Source: Deploy from a branch**, rama `main`, carpeta `/ (root)` → **Save**.
4. En 1–2 minutos queda disponible en `https://TU-USUARIO.github.io/NOMBRE-DEL-REPO/`.

## Estructura
- `index.html` — contenido
- `css/styles.css` — estilos (escala del diseño en vw, 16:9)
- `js/main.js` — patrón de fondo, animaciones al scroll, copiar Discord
- `assets/img/` — imágenes extraídas de tu diseño de Canva (WebP optimizado)
